# kitty-config

Personal [kitty](https://sw.kovidgoyal.net/kitty/) terminal configuration (JetBrains Mono Nerd Font, ctrl+shift copy/paste, shell integration).

## Files

| Source | Installed to |
| --- | --- |
| `kitty.conf` | `~/.config/kitty/kitty.conf` |

The shell is not set in this file, so kitty uses your login shell. Option is sent as Alt on macOS.
The `manifest` file is read by the [dotfiles](https://github.com/NBAFrigge/dotfiles) bootstrap.
